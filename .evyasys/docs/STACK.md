## Runtime

| Layer | Technology | Version | Role |
|---|---|---|---|
| Plugin platform | Claude Code (Anthropic) | — | Hosts all `/evyasys:*` commands; parses SKILL.md; runs hooks.js post-agent |
| Primary runtime | Node.js | ≥ 16.0.0 | Executes all hooks.js and scripts/lib/*.js |
| Secondary runtime | Python | 3.x (3.10 confirmed via __pycache__) | Runs scripts/repo_scan.py, scripts/lib/evyasys_config.py, integration helpers |
| Package manager | npm | bundled with Node.js | Manages node_modules; scripts defined in package.json |

## PM Tool Integrations

| Tool | API | Auth method | File |
|---|---|---|---|
| Azure DevOps | REST API v7.1 (`dev.azure.com/_apis/wit/`) | Basic auth — PAT encoded as `:<pat>` Base64 | `scripts/integrations/azure_devops.js` + `.py` |

## Security

| Component | Mechanism |
|---|---|
| Credential storage | AES-256-CBC, machine-bound key (`sha256(evyasys:{hostname}:{username})`), stored at `~/.evyasys/credentials` |
| Credentials file permissions | `0o600` — owner read/write only |
| Non-sensitive config | `{project}/.evyasys/project.yaml` — committed to git |
| Personal secrets | Never in project.yaml or git |
