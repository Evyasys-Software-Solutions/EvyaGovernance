# Finish-QA checklist

- [ ] Every TC has a recorded outcome (pass / fail / blocked).
- [ ] No P0 or P1 defects open against this story.
- [ ] Release notes use plain, user-facing language (run "no-tech-in-stories.md" lens).
- [ ] Roll-back plan documented (or explicitly N/A).
- [ ] Sprint tag applied (or noted in release notes if cross-sprint).
