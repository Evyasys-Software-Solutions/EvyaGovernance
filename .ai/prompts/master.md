# Master Prompt Style Guide

Use these principles in every prompt:
- be explicit about role
- define the task
- define the required output
- define the no-go rules
- define the quality standard
- define the confirmation rule

Recommended style:
- concise
- structured
- business-first
- action-oriented
- no technical jargon unless the workflow specifically allows it

Output should be predictable and easy to automate.
