# Rule: No Technical Details in Business Story

Do not include:
- classes
- methods
- endpoints
- DB schema
- code samples
- framework-specific implementation
- infrastructure design

Business story may include:
- business context
- workflows
- actors
- preconditions
- scenarios
- acceptance criteria
- out-of-scope
- assumptions
- business-level breaking changes

Technical impact can be captured separately in:
- repo impact analysis
- developer notes
- implementation plan
- QA notes
