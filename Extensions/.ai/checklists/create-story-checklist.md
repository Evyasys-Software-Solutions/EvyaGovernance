# Create Story Checklist

Before asking for confirmation:
- [ ] business context is complete
- [ ] roles are identified
- [ ] preconditions are complete
- [ ] workflow is clear
- [ ] business scenarios are present
- [ ] acceptance criteria are measurable
- [ ] dependencies are listed
- [ ] breaking changes are noted
- [ ] out-of-scope is explicit
- [ ] assumptions are listed
- [ ] open questions are listed
- [ ] repo impact has been checked
- [ ] no technical implementation details are included
- [ ] final self-review is complete
