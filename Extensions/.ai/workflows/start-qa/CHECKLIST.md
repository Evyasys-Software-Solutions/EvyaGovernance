# Start-QA self-review checklist

- [ ] Every AC has ≥ 1 positive and ≥ 1 negative test case.
- [ ] At least 2 edge cases covered.
- [ ] Regression suite covers every "files touched" area in the Dev Summary.
- [ ] Non-functional section is filled (or marked "N/A — internal API only", etc.).
- [ ] Test data + environments are explicit.
- [ ] Exit criteria are listed.
