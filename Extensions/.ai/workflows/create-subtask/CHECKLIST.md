# Self-review checklist (subtasks)

- [ ] Between 3 and 8 tasks.
- [ ] Each task has a unique title.
- [ ] Each task has an estimate.
- [ ] Each task lists impacted modules (or "N/A — design task").
- [ ] Every AC from the parent story is referenced by at least one task.
- [ ] Dependencies between tasks are explicit.
- [ ] No task contains language that should be in the story (business context).
- [ ] At least one task is a Test task (or testing is folded into every task with explicit unit/integration coverage).
